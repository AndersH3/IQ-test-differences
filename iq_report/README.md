## Rebuild the PDF

Run from this directory:

```sh
bash code/build_report.sh
```

Requires XeLaTeX, latexmk, BibTeX, KOMA-Script, the packages listed in the TeX
preamble, Latin Modern text/math fonts, and DejaVu Sans Mono. The supplied
figures allow compilation without rerunning R. The document uses A4 paper
with 18 mm side margins, 19 mm top and 20 mm bottom margins.

## Reproduce the computation

The programs require base R only. The reported runs used R 4.3.3 on 64-bit Linux.

```sh
Rscript code/iq_difference_simulation.R --out=results/main_run_new.txt
Rscript code/iq_report_extensions.R
```

The main program refuses to overwrite an existing output file; choose a new
filename. The supplement regenerates its own derived outputs. Both record R
session information. The main model and shared/independent mixture use five
million people each. The smooth mixture uses one million people. Seeds and
batch sizes are fixed in the code or command defaults.

To export the workbook, a Node environment with `@oai/artifact-tool` is needed:

```sh
node code/export_workbook.mjs .
```

This step is optional; the PDF and all R calculations can be reproduced without
that library. The workbook preserves exported R tables as fixed values and
clearly separates them from the editable formula-based model sheet. Numeric
source data are also provided in ordinary CSV form.

## Scope

The 10.70-point mean absolute gap and 22.07-point mean five-test range assume
joint normality, SD 15, equal means, and correlation 0.6 for every distinct pair.
Correlation alone does not determine these averages. The report supplies
rigorous proofs, counterexamples, conditional calculations, sensitivity analyses,
and limits on application to actual tests.

The printed appendices contain all analysis, simulation, figure, workbook-export,
and build code. The TeX/BibTeX sources are supplied here as editable files.
